# browser/

Code that runs **inside the web pages of a WebView**. Nothing here can see Java, Frida or the event vocabulary. Native code (`native/browser_delivery.js`) renders these files with run-time values and injects them with `evaluateJavascript`.

## Scripts

| Script (`BROWSER_SOURCES` key) | Files | Purpose |
|---|---|---|
| `observer` | `observer/00_namespace.js` … `observer/50_bridge_wrapper.js` | Installed once per page. Wraps page APIs and buffers page events. |
| `bridgeTaint` | `bridge_taint.js` | Asks the observer to wrap one sensitive bridge method. |
| `probe` | `probe.js` | Drains the event buffer and returns it as a JSON string. |

The `observer` fragments are concatenated **in file-name order inside one function** by `core/agent/build_agent.py`. They all share the local `state`, `copyArg`, `report`, the taint helpers and so on, so the order matters:

1. `00_namespace.js`: idempotent install, namespace, `state`
2. `10_serialize.js`: `copyArg`, `report` (buffer capped at 500 events)
3. `20_taint.js`: fingerprints, `rememberTaint` (capped at 200), `findTaint`, `taintsForArgs`
4. `30_intercepts.js`: `intercept()` for fetch, eval, window.open, postMessage, sendBeacon, location, XMLHttpRequest
5. `40_storage.js`: `Storage.prototype.setItem/getItem` taint propagation
6. `50_bridge_wrapper.js`: `state.wrapBridgeMethod`, then `return true`

## Placeholders

Run-time values are written as bare identifiers, so every file stays valid JavaScript. Native code replaces each one with `JSON.stringify(value)`:

| Placeholder | Value |
|---|---|
| `__SENTRY_NAMESPACE__` | Random per-run namespace, generated by native code at agent start |
| `__SENTRY_WEBVIEW_ID__` | Native WebView id (probe only) |
| `__SENTRY_INTERFACE_NAME__`, `__SENTRY_METHOD_NAME__`, `__SENTRY_SOURCE__` | Bridge method to wrap (bridgeTaint only) |

Template literals (`${…}`) are not allowed in this directory; the bundler rejects them.

## Rules

- Don't reference `Java`, `EVENT_TYPE`, `console.log` or `send()`. Page code reports only through `state.events`.
- Every file starts with a `// browser: …` header and stays within 430 lines.
- To intercept a new page API, add an `intercept(...)` call to `observer/30_intercepts.js`. For a larger feature, add a new numbered fragment and list it in `core/agent/manifest.json`. Then run `python3 -m unittest tests.test_browser_parity tests.test_layering_browser`.
